
# My Portfolio

A React site that shows the projects I built in Level 2.

## Components

| Component | What it shows | Where its values come from | What it remembers |
| --- | --- | --- | --- |
| `Header` | my name and a line about me | typed into the JSX | - |
| `Hero` | my hero photo | `heroPhoto`, which calls `imageUrl` | whether the photo is in color or black and white |
| `Fortune` | a random fortune | a list and `randomNumber` | which fortune is showing |
| `Footer` | &copy; and the current year | the year the page is opened | - |
| `DataPlaylistPortfolioCard` | one project: its name, description, and two links | variables inside the component | its likes and whether it shows more |
| `SignUpPagePortfolioCard` | one project: it's name, description, and two links |  variables inside the component | its likes and whether it shows more |
| `ApiTutorialPortfolioCard` | one project: it's name, description, and two links | variables inside the component | its likes and whether it shows more|
| `CapstonePortfolioCard` | one project: it's name, description, and two links | variables inside the component | its likes and whether it shows more |
| `GreetingCardGeneratorPortfolioCard` | one project: it's name, description, and two links | variables inside the component | its likes and whether it shows more |
| `ClickLabPortfolioCard` | one project: it's name, description, and two links | variables inside the component | its likes and whether it shows more |
|  |  |  |
